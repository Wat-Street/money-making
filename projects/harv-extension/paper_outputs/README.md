# Paper Outputs

This folder contains generated paper material that is useful but is not the final submission bundle.

## Contents

- `alternate_paper.tex` - Alternate manuscript export.
- `paper_assets/figures/` - Working figure exports and source-format companions.
- `paper_assets/tables/` - Working/generated table exports and source CSV companions.
- `archive/` - Preserved probes and older build products.

Final submission inputs live in `../final_paper/`.
