# Working Paper Assets

These are generated or working paper assets that are not the canonical final-paper inputs.

## Folders

- `figures/` - Working figure exports in PDF/SVG/PNG formats.
- `figures/previews/` - Preview-only PNGs used for visual inspection.
- `figures/supplemental_section5_ablation/` - Preserved supplemental Section 5 ablation/support charts.
- `tables/` - Working/generated table fragments and source CSV companions.

The final manuscript uses `../final_paper/assets/`, not this folder.
