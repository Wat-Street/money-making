# PHQO

Prime-Harmonic Quotient Operator.

This exploratory challenger computes a CP-orthogonal prime-harmonic energy field on the current lag path, maps the field back to calendar-lag weights, and applies Gibbs modulation to a static CP/HAR-style base weight distribution.

The final forecast is scaled by the current `CP_REPO_FRESH` prediction. When `gamma=0`, the multiplicative ratio is exactly one, so the model nests corrected repo CP.
