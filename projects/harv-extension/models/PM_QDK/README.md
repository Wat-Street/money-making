# PM_QDK

Prime-Modular Quotient Diffusion Kernel.

This exploratory challenger keeps `CP_REPO_FRESH` as the benchmark denominator but changes the comparison geometry. The lag path is projected through a CP path matrix, the CP-invisible residual is embedded in the `Z2 x Z3 x Z5` prime torus, and a diffusion-weighted harmonic kernel forecasts from prior rows only.

It is not an additive CP+PM feature block.
