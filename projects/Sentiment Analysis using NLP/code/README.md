# ML Models

Each folder contains an ml model that was researched and developed. Contains documentation on how to run it and what hyperparam tuning was done.

The notebook reads third-party credentials from environment variables. Set the
ones required for the cells you intend to run: `ALPHA_VANTAGE_API_KEY`,
`X_API_KEY`, `X_API_SECRET`, `X_ACCESS_TOKEN`, `X_ACCESS_TOKEN_SECRET`, and
`NEWS_API_KEY`.
